# Creative Claw icon

The violet frame and mint play/edit mark in `favicon.svg` was drawn for this
Nebius application copy on October 29, 2026. It is an original vector asset,
distributed under this repository's existing license. The PNG and ICO icons
are raster exports of that SVG.

It replaces the red robot-lobster `creative-claw.png` introduced in the original
Creative Claw repository at commit `56e3ce672d37204948f845a0fe59f0a0ebc427da`.
The prior SVG favicon also depicted a lobster. This branding change does not
change or remove the application's OpenClaw attribution or licenses, and does
not modify the original Creative Claw or Meta application copy.

Meta event copy: on November 2, 2026, `apple-touch-icon.png`,
`creative-claw.png`, `favicon-32.png`, `favicon.ico`, `favicon.svg` and this
file were copied unchanged from the Creative Claw Nebius event copy. The
statement above was written for the Nebius copy; reusing the icon here is a
deliberate later choice, not new artwork for the Meta event.
